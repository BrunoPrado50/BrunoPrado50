### Projeto em destaque

**[NetHelp N1 — Assistente de suporte no Telegram](https://github.com/BrunoPrado50/network-support-rag-bot)**

Protótipo de um assistente para triagem inicial de problemas de conexão à internet. Consulta uma base técnica com RAG, orienta verificações simples e prepara um resumo para encaminhamento ao suporte humano.

O projeto reúne **Python, LangChain e integração com as APIs do Telegram e da Groq**.
